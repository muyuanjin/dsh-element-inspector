# Security Policy

## Supported versions

Security fixes are provided for the latest release only.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories for this repository. Do not include credentials, private conversation content, or local profile files in a public issue.

Element Radar runs locally. It reads runtime source files only from packages declared in the active DSH profile, opens verified installed-package paths with the operating system's file manager, and stores preferences through the official DSH settings service. It does not upload inspected element data.
